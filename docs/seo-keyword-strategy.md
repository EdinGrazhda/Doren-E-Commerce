# Keyword and page map

This is a page-intent map based on the current site routes, category names and product catalog. It contains no search-volume, difficulty, ranking, or demand claims. Validate query demand, language, and market before rewriting copy or building new landing pages. Each existing URL should serve one main intent.

| Existing URL | Page role | Primary intent/topic | Evidence and next step |
| --- | --- | --- | --- |
| `/` | Storefront homepage | Men's clothing at Doren, Prizren | Existing homepage and market language; confirm the location and delivery statements with the business. |
| `/collections/polos` | Collection | Men's polo shirts | Existing category; add a useful collection explanation using product facts, then confirm demand in Search Console. |
| `/collections/knitwear` | Collection | Men's knitwear and sweaters | Existing category; use the live catalog's knit and sweater products, not unsupported material claims. |
| `/collections/shirts` | Collection | Men's shirts | Existing category; distinguish poplin or other styles only when the catalog data supports it. |
| `/collections/trousers` | Collection | Men's trousers | Existing category; distinguish linen or tailoring only where the relevant product record confirms it. |
| `/products/{slug}` | Product detail | Specific product name and its verified attributes | Product title, description, currency, SKU, price and stock are drawn from the product record. Do not add reviews, composition, fit, shipping guarantees, or availability claims without evidence. |
| `?search=...` | Search results | Navigational product lookup | Internal search is `noindex`; do not target search-result URLs as landing pages. |
| `?page=N` | Paginated collection | Continued collection browsing | Page number stays in its canonical URL when valid; search/filter variations stay out of the sitemap. |

Current seed data illustrates the above categories with products such as Pima Cotton Polo, Merino Crew Knit, Cotton Poplin Shirt and Tailored Linen Trousers. Seed data is not sufficient proof that those items remain live, in stock, or accurately described in production. Check the catalog before writing recommendations or publishing content.

Search Console, analytics reports, customer search data, and approved keyword-provider results are not imported here. Treat any suggested question or long-tail phrase as a hypothesis until verified. Avoid creating more city pages or translations: the project currently provides one storefront language and no verified alternate location or translation pages.
